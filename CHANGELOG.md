# Changelog

## 1.1.0 - 2026-10-08

### Added

- Open-source project structure with local build script and GitHub Actions workflow.
- Dynamic version injection for development and release builds.
- Bilingual README in English and Chinese.
- Complete metadata for every Rainmeter skin.

### Improved

- GPU usage aggregation now uses Windows `GPU Engine` samples grouped by adapter LUID and engine type.
- GPU progress bar scales proportionally when total usage exceeds 100%.

### Included

- NeoDesk System, Clock, Greeting, Network, and Visualizer skins.
- MiSans font family.
- English and Chinese language files.
