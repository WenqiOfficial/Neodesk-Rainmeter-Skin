# Credits

NeoDesk is built on top of several excellent tools and resources:

- **Rainmeter** — the desktop customization platform.
- **MiSans** — the bundled font family used across the skins.
- **Windows UsageMonitor counters** — used for CPU, RAM, GPU, and network metrics.
- **AudioLevel plugin** — used by the visualizer skins.

The project itself is maintained by WenqiOfficial.
